# Dream

Interactive 3D pieces that run in the browser, published with GitHub Pages at
https://brigham4210.github.io/Dream/

- **[Dream Garage](https://brigham4210.github.io/Dream/Garage/)**: a 3D showroom holding a 1977 Leyland Mini 1000 Mk IV and a 1966 Chevrolet C10 stepside. Drag to walk around, scroll to zoom, click doors, hoods, boots and tailgates to open them.

Everything is static HTML and JavaScript; three.js is loaded from a CDN, so an internet connection is needed.
